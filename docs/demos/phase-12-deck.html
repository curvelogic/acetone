Slide 7 · Process — a breach, disclosed

“Main is always green” was broken for three merges

I merged #286 while its public-API freeze job was red (a misread check count), and my next two merge chains joined watch-and-merge with ; instead of &&, so failed watches did not gate. #289's bless repaired main. No wrong code — the symbols were deliberate, reviewed API; the snapshot ratification was missing.

Proposal: make the freeze job and build-and-test required checks, so a red gate blocks merges mechanically rather than by agent discipline. Merge chains are &&-only from here.
