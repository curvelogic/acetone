Slide 5 · Problems that arose

What review caught, and what the process dropped

  • #311 — a rename could store an undeclared type’s edges under a declared discriminator, falsifying ADR-0082’s provenance premise while the PR’s own doc comment said it could not. Reproduced, fixed, red-checked.
  • #312 — in the new half-aborted state an ordinary write cleared the empty-conflicts mark, so the next commit landed merge content as single-parent work. Now refused.
  • #304 — pinning isolation surfaced a real cross-handle gc read race.
  • Lost tracker writes — closes for d5is.3, 00wh, 7ldo and omk never reached the tracker; d5is.13 was never relayed. Repaired retrospectively; the PRs are the record.
  • A ; in a rebase-and-push chain — pushed nothing, but repeats the Phase 12 lesson: && only.

Slide 6 · Decisions taken

Four ADRs, two of them governing

  • ADR-0079 — the phase definition, accepted at the opening with seven rulings.
  • ADR-0080 (governing) — refer to the owner by role; a phase opens on the owner’s first-hand instruction. ADR-0081 extends the role rule to live material.
  • ADR-0082 (governing: one sentence in spec §2) — a merged discriminator change is a conflict, judged by which side wrote the edge.
  • Recorded deviations, each reviewer-endorsed: unrepresentable numbers refused (#300); one entity map column (#301); rekey/rename-rel-type keep the neutral author (#305); renames refuse one-sided discriminator mismatch (#311); writes refused mid-abort (#312).
