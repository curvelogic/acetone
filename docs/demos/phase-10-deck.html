Context

Where the phase started, and what pulled it

Phase 9 left acetone measurably correct at size. Phase 10's premise (ADR-0068): capabilities are use-pulled, not roadmap-pushed. The pull arrived on schedule — a private external application chose acetone as its fact store: facts with an open predicate vocabulary, ingested onto scratch branches, three-way merged into a curated ref, co-tenant in a repository the user owns.

  • Strand 1 — quality debt: the 7qw P2 tier: freeze-gate blind spots, scan-budget under-counts, memoisation, costed seeks, typed relationship properties, binder scoping.
  • Strand 2 — open vocabulary: autodeclare, declarative schema, surrogate identity, phrase predicates, an aliasing decision.
  • Convergence: the tenant's consolidated feedback, which reshaped the roadmap mid-phase (with Greg's direction) and pulled a deferred feature into scope.
What was done · 1 of 3

Quality: the workbench stopped trusting itself politely

  • Freeze gate whole-surface — six per-crate snapshots; caught three real API changes during the phase itself.
  • Pathologies refuse cheaply — scan memoisation + costed seek choice + byte-weighted budgets + a 60 s CLI wall clock: the query that burned 703 s of real work before its typed refusal now refuses in bounded time.
  • Typed relationship properties — enforced at write, declare (streamed backfill), and merge; discriminators checked in both stored positions.
  • Binder honesty — the four ORDER BY/aggregation error families conceded at PR #33 are now enforced via structural matching over bound trees. Getting the rule right took three full-TCK calibration rounds and two review rounds; conformance rose 33 scenarios while becoming stricter.
What was done · 2 of 3

Open vocabulary: coin it, declare it, resolve it later

  • Autodeclare (opt-in, three surfaces) — a write may coin a relationship type; reads never coin; a coining write mid-merge is refused (review found it would have silently resolved schema conflicts).
  • schema apply — declarative bootstrap from the exported JSON document: transactional, idempotent, never removes entries, announces what a change drops; the first CLI surface for surrogate and discriminated declarations.
  • Surrogate identity works — spec §2's ULID promise was unimplemented; now minted at CREATE, visible to the creating query, with the declared string key that keeps point-lookups seeking.
  • ADR-0071: assert-then-identify — equivalence as an ordinary edge now; convergence as a deliberate future identify. The review disproved the draft's merge claim by running it: divergent identifications merge cleanly and silently duplicate — detection is now a stated design requirement, not an assumed property.
What was done · 3 of 3

Parallel edges: from reserved slot to full surface

Tenant discussion exposed that parallel edges were crippled: declarable and import-writable, but Cypher couldn't create one — and item-wise SET/DELETE on imported ones targeted the wrong edge, a hazard live in every release since 0.1 (DETACH DELETE failed outright; a delete-plus-create could silently clobber an unrelated edge).

Now: bound edges keep their exact identity; a declared discriminator property resolves into the key at CREATE/MERGE; the value reads back under its declared name (even on record-empty imported edges); identity is immutable under SET/REMOVE. Declarable, importable, creatable, matchable, curatable.

Scope added mid-phase by ADR-0073 with Greg's confirmation; the ratified exit criteria were unchanged.
